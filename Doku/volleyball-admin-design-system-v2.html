Game status rule

Status is calculated from score values; do not store or edit a separate “ended” flag in the UI.

Not playedscoreA == null || scoreB == null
In playscoreA != null && scoreB != null && scoreA < 25 && scoreB < 25
EndedscoreA >= 25 || scoreB >= 25
